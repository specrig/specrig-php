# specrig/symfony

specrig for a Symfony 7.4 or 8 service: the kernel booted per case, its HTTP
client, transports and console stood in for, and the cases written and approved
before the code.

```bash
composer require --dev specrig/symfony
```

How to lay the harness out and write the cases:
[specrig/specrig-php](https://github.com/specrig/specrig-php#getting-started).

This repository is a read-only copy of `packages/symfony` in specrig-php, kept in
step by specrig-php's release workflow. Issues and changes go to
[specrig-php](https://github.com/specrig/specrig-php).
